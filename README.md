# 🍔 Swiggy Excel Dashboard

## 📊 Project Overview

This project is an **interactive Swiggy Sales Dashboard created using Microsoft Excel**. The dashboard analyzes food delivery data and provides useful insights into sales performance, customer behavior, restaurant performance, and order trends.

The project demonstrates how **Excel, data cleaning, data analysis, Pivot Tables, Pivot Charts, and interactive dashboards** can be used to transform raw data into meaningful business insights.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze Swiggy order and sales data.
- Understand overall sales performance.
- Identify top-performing restaurants and food categories.
- Analyze customer ordering patterns.
- Track order volume and revenue trends.
- Create an interactive and easy-to-understand dashboard.
- Generate actionable business insights from the data.
